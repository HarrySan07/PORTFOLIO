# HariPrasath P --- Portfolio Design Lab

A collection of **21 independently designed portfolio concepts** for a
Mechanical Engineering student.

This project explores how the same professional information can be
presented through completely different visual systems, layouts,
animations, and interaction styles.

## Project Overview

The Portfolio Design Lab contains 21 separate HTML portfolio designs.

Each design keeps the core portfolio information consistent while
changing the:

-   Visual identity
-   Layout structure
-   Typography
-   Navigation style
-   Information presentation
-   Animation style
-   Color system
-   Interaction approach
-   Overall user experience

The purpose is to experiment with different approaches before selecting
a final portfolio design.

## Design Philosophy

The main idea behind this project is simple:

> **Same engineer. Same information. Completely different experience.**

Rather than making 21 versions that only change colors, each concept
experiments with a different way of organizing and communicating the
portfolio.

The designs range from technical engineering interfaces and blueprints
to editorial layouts, industrial systems, command consoles, and
cinematic experiences.

## Running Locally

No build system is required for the basic versions.

Open the project folder in VS Code and use **Live Server**, or open
`index.html` directly in a browser.

For the best experience, use Live Server because some browser
environments may restrict local iframe behavior.

## GitHub Pages

The repository can be deployed directly through GitHub Pages.

The main entry point is:

``` text
index.html
```

Once deployed, the GitHub Pages URL opens the design selector, from
which all 21 portfolio designs can be accessed.
