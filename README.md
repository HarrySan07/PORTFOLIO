# 🧱 Technology Stack

```text
Portfolio Website
│
├── HTML5
│   └── Page Structure & Portfolio Content
│
├── CSS3
│   ├── Responsive Design

│   ├── Scroll Reveal
│   ├── Active Navigation
│   └── Desktop Interaction
│
└── External Animation CSS
    └── Portfolio 1 Cinematic Opening Animation
```

### Architecture

The portfolio is organized into a main HTML file and a dedicated CSS file for the opening animation.

```text
index.html
    │
    ├── HTML
    ├── Main Portfolio CSS
    └── JavaScript
            │
            ▼
      animation.css
            │
            └── Portfolio 1 Opening Animation
```

The separate animation stylesheet makes it easier to replace or experiment with different opening animations without restructuring the main portfolio.
