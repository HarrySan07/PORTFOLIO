## 🚀 How It Works

The main entry point is:

**`index.html`**

When the GitHub Pages website is opened, `index.html` displays the **21 design previews**.

Each preview acts as a link to its corresponding design.

For example:

- Design 01 → `01.html`
- Design 02 → `02.html`
- Design 03 → `03.html`
- ...
- Design 21 → `21.html`

This makes it possible to compare all the concepts from a single page.

## 🧩 Current Development Approach

The portfolio is being developed in stages.

### Stage 1 — Design Exploration

Create 21 different concepts with different:

- UI styles
- Layouts
- Animations
- Color schemes
- Interaction styles

### Stage 2 — Design Refinement

Each design will be individually improved by adding:

- Better animations
- More polished UI
- Responsive layouts
- Better typography
- Improved navigation
- Interactive elements
- Engineering-focused visual elements

### Stage 3 — Final Selection

After comparing the 21 concepts, one design will be selected as the primary portfolio.

The selected design will then receive the complete final development treatment.
